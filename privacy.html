Privacy Policy — Attachment Downloader

Last updated: 2026-10-07

Data accessed

The app uses the Gmail API with the read-only scope (https://www.googleapis.com/auth/gmail.readonly) to search messages and download their attachments.

How data is used and stored

  • Attachments are saved only to the local computer of the user running the tool.
  • OAuth tokens are stored locally on that computer and are never shared.
  • No data is sent to any server other than Google's APIs. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
